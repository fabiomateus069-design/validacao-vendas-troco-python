# 🤝 Contribuindo para o Projeto

Obrigado por considerar contribuir para o **Sistema de Validação de Vendas e Troco**! 

## Como Contribuir

### 🐛 Reportar Bugs

Antes de criar um relatório de bug, verifique a [lista de issues](https://github.com/fabiomateus069-design/validacao-vendas-troco-python/issues) para confirmar que o bug ainda não foi reportado.

Ao criar um relatório de bug, inclua:
- **Título descritivo**
- **Descrição exata do comportamento observado**
- **Comportamento esperado**
- **Passos para reproduzir**
- **Ambiente** (Python versão, SO, etc.)

### ✨ Sugerir Melhorias

Sugestões são sempre bem-vindas! Abra uma issue descrevendo:
- **Caso de uso**
- **Comportamento esperado**
- **Possível implementação** (opcional)

### 📝 Pull Requests

1. **Fork o repositório**
   ```bash
   git clone https://github.com/SEU_USUARIO/validacao-vendas-troco-python.git
   cd validacao-vendas-troco-python
   ```

2. **Crie uma branch**
   ```bash
   git checkout -b feature/sua-feature
   ```

3. **Faça suas mudanças**
   - Mantenha o código limpo e bem comentado
   - Siga o padrão de estilo Python (PEP 8)
   - Adicione testes se aplicável

4. **Commit suas mudanças**
   ```bash
   git add .
   git commit -m "Adicionar: breve descrição da mudança"
   ```

5. **Push para sua branch**
   ```bash
   git push origin feature/sua-feature
   ```

6. **Abra um Pull Request**
   - Descreva claramente o que foi mudado
   - Referencie qualquer issue relacionada

## Diretrizes de Código

- Use **variáveis descritivas**
- Adicione **comentários claros**
- Siga **PEP 8**
- Teste seu código antes de enviar

## Perguntas?

Sinta-se livre para abrir uma [issue](https://github.com/fabiomateus069-design/validacao-vendas-troco-python/issues) com a etiqueta `question`.
